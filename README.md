# render-doc

Architecture documentation for **QuarterMaster**, the blueprinting feature of the Render platform: it turns uploaded telecom network designs into Render tasks.

| Document | What it is |
|---|---|
| [Design context](docs/design-context.md) | Baseline from the 6 Nov 2026 architecture review: user flow, drafting pipeline, task flow and activities, AI ownership, forms, knowledge strategy and spend findings, open items. |
| [Architecture Decision Log](docs/architecture-decision-log.md) | Decisions agreed (QM-nn), decisions needing Render approval (RA-nn), open items (OPEN-nn), and the status of the earlier ADRs. |
| [Target Architecture Reference](docs/target-architecture-reference.md) | Target system: context, components, data ownership, pipeline stages, sequence, refinement loops, deployment, external contracts, cross-cutting rules. |

The decision log and target architecture are exported from their Claude Docs originals, which remain the editable versions:

- Architecture Decision Log: https://claude.ai/artifact/6pz5fDi6MQpS4UyaGmb8uf
- Target Architecture Reference: https://claude.ai/artifact/L5MUwTMShtJgqtGtRGDUMK
